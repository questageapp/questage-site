How to install

  1. Download

    Pick a pack and download the .quefx or .quepal file.

  2. Import in QUE

    Open Menu → FILE → IMPORT FX or IMPORT PALETTES and choose the file.

  3. Done — nothing is replaced

    New items are added to your library. If a name already exists, the new one is added as “(2)”. Nothing is deleted.
