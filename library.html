How to install

01

Download

Pick a pack and download the .quefx or .quepal file.

02

Import in QUE

Open Menu → FILE → IMPORT FX or IMPORT PALETTES and choose the file.

03

Done. Nothing is replaced

New items are added to your library. If a name already exists, the new one is added as “(2)”. Nothing is deleted.

Share your own

Made an FX you’re proud of? Send the .quefx file to info@matukufilm.com and we may add it to the Library. There are no accounts or online uploads, just email.

Files contain only effect and colour definitions. No personal data, no Bridge information.
